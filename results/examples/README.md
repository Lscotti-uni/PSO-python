# Versioned Result Examples

This folder contains a very small subset of generated artifacts that are safe
to keep in GitHub as reproducible examples.

Included examples:

- `single_run/summary.json`
- `single_run/history.csv`
- `single_run/convergence.png`
- `benchmarks/benchmark_summary.csv`
- `benchmarks/benchmark_summary.json`
- `analysis/benchmark_mean_convergence.png`
- `analysis/benchmark_speedup.png`
- `analysis/benchmark_final_fitness_boxplot.png`

The full benchmark, grid-search, and protocol outputs remain local to avoid
turning the repository into a large data dump.
