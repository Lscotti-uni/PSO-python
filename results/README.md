# Resultados De Ejemplo

Esta carpeta contiene artefactos generados con los scripts del proyecto:

- `examples/`: pequeno subconjunto versionado para GitHub con artefactos
  representativos y faciles de inspeccionar.
- `runs/`: ejecuciones individuales con `summary.json`, `history.csv`, `run.log`
  y, cuando aplica, `trajectory.npz`, `frames/` y `swarm.gif`.
- `benchmarks/`: ejemplo de suite de benchmarks.
- `grid_search/`: ejemplo de búsqueda de hiperparámetros.
- `analysis/`: plots agregados creados desde resultados ya guardados.

Los ejemplos incluidos son reducidos para que el repositorio siga siendo
manejable. Para el protocolo experimental completo, lanza los scripts con
las configuraciones YAML correspondientes.
