# Example Results

This directory contains artifacts generated by the project scripts:

- `examples/`: small versioned subset intended for GitHub and quick inspection
- `runs/`: individual executions with `summary.json`, `history.csv`, `run.log`,
  and, when available, `trajectory.npz`, `frames/`, and `swarm.gif`
- `benchmarks/`: benchmark-suite outputs
- `grid_search/`: hyperparameter-search outputs
- `analysis/`: aggregate plots generated from previously saved results

The versioned examples are intentionally small so that the repository remains
manageable. The full protocol can be reproduced with the provided YAML
configurations and scripts.
